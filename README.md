## For JavaScript Developers

Some quick differences:

| JavaScript  | Python     |
| ----------- | ---------- |
| Object      | Dictionary |
| Array       | List       |
| ===         | ==         |
| null        | None       |
| console.log | print      |

Example comparison:

JavaScript

```
const user = { name: "Yogesh", age: 20 };
console.log(user.name);
```

Python

```
user = {"name": "Yogesh", "age": 20}
print(user["name"])
```
